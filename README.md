# dEXE's Kodi Add-ons Repository
 
The dEXE repo brings together tested add-ons for movies, TV shows, live TV, subtitles, music and programs, with a special focus on what ex-Yu users need. It's perfect for beginners and for anyone who sets up Kodi on several devices: easily install one repo and get all the best add-ons in one place.
 
**Website:** <a href="https://deklica.github.io" target="_blank">deklica.github.io</a> — repo download links, add-on catalog, references and tutorials.
